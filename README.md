# 울림 (Woollim)

**청각장애 운전자를 위한 실시간 위험음(사이렌·경적) 감지·알림 시스템**

차 안 마이크로 들어오는 소리를 Raspberry Pi 4에서 실시간으로 분석해 **사이렌**과 **경적**을 감지하고,
BLE로 운전자의 스마트폰에 보내 **화면 경고와 진동**으로 알려 줍니다.

> 울림은 운전을 돕는 **보조 장치**입니다. 모든 위험음을 감지한다고 보장하지 않습니다.

---

## 왜 만들었나

청각장애 운전자는 구급차·소방차 사이렌이나 주변 차량의 경적을 듣기 어렵습니다.
울림은 이런 소리를 **시각(화면)과 촉각(진동)** 신호로 바꿔, 길을 비켜 주거나 주의해야 할 순간을 놓치지 않도록 돕습니다.

## 시스템 구성

```
 ┌──────────────┐     ┌──────────────────────────────┐   BLE Notify   ┌───────────────────────────┐
 │  차량 마이크   │ ──▶ │  Raspberry Pi 4 (감지 장치)     │ ─────────────▶ │  Android 앱 (알림)           │
 │  16 kHz 모노  │     │  · YAMNet 기반 TFLite 모델      │   HazardEvent  │  · 긴급: 전체 화면 + 강한 진동  │
 └──────────────┘     │  · 3창 중 2창 판정, 무음 필터     │      JSON      │  · 주의: 상단 배너 + 짧은 진동  │
                      │  · 음량 추세로 접근/멀어짐 추정    │ ◀───────────── │  · 감지 기록, 시연 모드        │
                      └──────────────────────────────┘   주행 속도      └───────────────────────────┘
```

## 주요 기능

| 기능 | 설명 |
|---|---|
| 위험음 감지 | 사이렌·경적을 0.5초마다 판정 (최근 2초 소리 기준) |
| 위험 단계 | **긴급**(접근하는 사이렌) · **주의** · **기록** 3단계. 정차 중(0 km/h)이면 긴급을 주의로 낮춤 |
| 접근/멀어짐 | 감지 구간 음량(dB) 기울기로 `가까워지는 중` / `멀어지는 중` / `거리 유지` 추정 |
| 다른 앱 위 경고 | 내비게이션을 켜 둔 상태에서도 오버레이로 경고 표시 |
| 진동 패턴 | 화면을 보지 않아도 진동만으로 단계를 구분 (긴급: 길게 반복, 주의: 짧게 2회) |
| 기록·시연 모드 | 감지 기록 화면, Pi 없이 가짜 이벤트로 알림을 확인하는 시연 모드 |

## 감지 모델 (v1)

- **구조**: AudioSet 사전학습 [YAMNet](https://github.com/tensorflow/models/tree/master/research/audioset/yamnet)(고정) 임베딩 → max pooling → Dense(256) → Dropout(0.3) → Softmax 3클래스 `[배경, 경적, 사이렌]`
- **입력**: 2초 창(16 kHz, 32000 샘플), 0.5초 간격으로 추론
- **후처리**: 최근 3창 중 2창 이상 임계값 초과 시 감지, 강한 경적은 1창 즉시 판정, 같은 클래스 3초 쿨다운
- **무음 필터**: 시작 3초 동안 주변 소음을 측정해 그보다 3 dB 이상 큰 소리만 판정 → 조용할 때의 오경보 제거
- **데이터**: 공개 데이터셋 5,115개 클립(사이렌 2,501 · 배경 1,744 · 경적 870), 출처 그룹 기준 train/val/test 분할(누수 검사 통과)

**시험셋 성능** (762 클립)

| 클래스 | Precision | Recall | F1 |
|---|---|---|---|
| 배경 | 0.839 | 0.960 | 0.896 |
| 경적 | 0.792 | 0.717 | 0.753 |
| 사이렌 | 0.989 | 0.928 | **0.957** |

Macro F1 **0.869** · TFLite 모델 13.9 MB · 추론 28 ms/창 (개발 PC CPU 기준)

자세한 실험 결과: [`ml/v1/RESULTS.md`](ml/v1/RESULTS.md) · 이전 모델(v0)과 학습 노트북: [`ml/MODEL_CARD.md`](ml/MODEL_CARD.md)

## 빠른 시작

### 1. 앱 빌드
JDK 21 필요 (Android Studio 번들 JDK 25는 Gradle 8.9와 호환되지 않음)

```bash
cd android
./gradlew assembleDebug
```

### 2. Pi 실행
```bash
cd ~/woollim
pip install -r pi/requirements.txt
cd pi
python main.py --fake      # 가짜 시나리오로 BLE 연결 확인
python main.py             # 실제 마이크 + 모델 v1
```
앱에서 **설정 → 시연 모드 끄기**를 하면 Pi(`Woollim`)를 자동으로 찾아 연결합니다.

## 통신 규격

| 항목 | UUID | 내용 |
|---|---|---|
| 서비스 | `8f1e0001-6b2c-4d3a-9e5f-77a1c0d2e301` | |
| event (Notify) | `8f1e0002-…` | `HazardEvent` JSON 한 줄 (20 byte 조각 + `\n`) |
| level (Notify) | `8f1e0003-…` | 마이크 레벨 1 byte, 10 Hz |

```jsonc
// Pi → 앱
{"v":1,"id":42,"cls":"siren","lvl":"urgent","conf":0.94,"trend":"approach","dur_ms":2300,"t_pi":1732412345678}
// 앱 → Pi
{"v":1,"speed_kmh":0,"t_app":1732412345700}
```
