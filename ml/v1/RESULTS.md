## 6. 실시간 판정 조건 선택 — 실제 마이크, WASAPI 배타 모드 녹음 (`06_threshold_and_realtime_study/`)

- 비교: 임계값 0.7/0.8/0.9/0.95/기존 × 3중2 켬/끔 × AGC 끔/20/40 dB × 무음필터 끔/+3/+6/+10 dB
- 기준: 실제 dev 녹음 오경보 ≤ 1.0/분 AND validation 배경 경보율 ≤ 0.05 → 만족 11개 조합 중 dev 감지 최대
- **선택: {'threshold': '기존', 'rule': '3중2', 'agc': 'off', 'silence_gate': '켬 m3'}** → 임계값 경적 0.9803, 사이렌 0.9996 (validation 값 그대로)
- 실제 dev: 감지 2/4, 오경보 0.0/분 | 실제 test(확인용): 경적 1/2, 사이렌 1/2, 오경보 무음 0·배경 0
- 녹음 구성: dev·test 각각 경적·사이렌을 가까이(30 cm) 1회 + 멀리(1~2 m) 1회. 가까이 재생은 감지, 멀리 재생(마이크 레벨이 무음보다 3~5 dB 큰 수준)은 미감지 (`real_mic_window_probs.csv`)
- 공유 모드(Windows 기본) 녹음(20261128_173611)은 Windows 소음 억제가 사이렌·경적을 1~2초 뒤 -93 dBFS 로 지워 선택에서 제외. 노트북 스피커→마이크 재생은 에코 제거로 사용 불가 (`loopback/`)

## 7. 실시간 감지 테스트 로그 (`07_realtime_tests/`)

- 실시간 실행 로그(window 별 확률·RMS·활동도·추론시간·경고), 요약 JSON, 마이크 보정값, 실제 환경 녹음(`real_recordings/`)
- 최종 설정 실시간 세션 `realtime_20261128_175846_tflite.csv` (사용자 직접 테스트): 274.5 s, window 546개, 무음 판정 293개(54%), 처리시간 중앙값 0.8 ms(무음 window 는 추론 생략), 경고 6회(사이렌 1회 9.5 s, 경적 5회 36.0·39.0·216.5·241.5·264.0 s). 창을 직접 닫아 종료되어 요약 JSON·녹음 WAV 는 생성되지 않았고, 재생한 소리의 정답 기록이 없어 정탐/오탐은 판정하지 않았다.
- 정답 라벨이 있는 실제 마이크 평가는 6번의 녹음 분석뿐이다. 그 밖의 실시간 세션 로그는 정답 라벨이 없어 정확도를 계산하지 않았다.

## 측정하지 않은 것
- mean·meanmax pooling 의 test 성능
- 실제 도로·차량 환경 성능, 장시간(1시간 이상) 연속 운용 오경보율
- 다른 PC·다른 마이크에서의 성능 (개발 PC 의 인텔 스마트 사운드 마이크 배열에서만 측정)
